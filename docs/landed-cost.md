# Автоматический расчёт себестоимости импорта (landed cost)

**Статус:** планируемая функциональность (предусмотреть в модуле `procurement`).
**Зачем:** убрать ручной труд закупщика.

## Бизнес-процесс

**Как сейчас:** при приходе товара (импорт из Китая) закупщик **вручную вносит
себестоимость в 1С**, прикидывая её из инвойса и расходов.

**Как делаем в ERP:** себестоимость единицы (**landed cost**) считается
**автоматически** = стоимость по инвойсу поставщика **+ все сопутствующие расходы**,
распределённые на номенклатуру. Закупщик ничего не вбивает — он только заводит
инвойс и расходы (или они подтягиваются), система считает себестоимость сама и
передаёт её на склад/в учёт.

## Что входит в себестоимость (состав расходов)

Распределяемые на партию доп.расходы (allocation):
- международный фрахт / доставка (море / авиа / авто);
- таможенная пошлина и таможенный сбор;
- акциз (если применим);
- услуги брокера / декларанта;
- сертификация / декларирование соответствия;
- страхование груза;
- внутренняя логистика до склада;
- банковские комиссии / конвертация валюты;
- прочие прямые расходы партии.

**Не входит** (отметить флагом «возмещаемый»):
- НДС при ввозе — обычно возмещаемый, в себестоимость **не** включается.

## Входные данные

1. **Инвойс поставщика**: позиции (SKU, кол-во, цена), валюта, сумма.
2. **Доп.расходы партии**: тип, сумма, валюта, признак «возмещаемый», база распределения.
3. **Курс валют** на дату оприходования / ГТД (многовалютность).
4. **База распределения** (настраиваемо): по стоимости (по умолчанию), по весу,
   по объёму или по количеству.

## Результат

- **landed_unit_cost** по каждой SKU (себестоимость единицы) в учётной валюте;
- полная себестоимость партии и раскладка расходов (для прозрачности и аудита).

## Где в воронке считается

Привязка к стадиям `procurement` (`stages.py`):
`po` (Заказ) → `supply` (Производство) → **`qc` (Приёмка)**.

Расчёт **финализируется на приёмке (`qc`)** — к этому моменту известны фактические
расходы (ГТД, фрахт). Именно стадия `qc` уже триггерит приход на склад
(`procurement.received`). Себестоимость кладётся в приход.

> **Реализовано на сейчас (`_fixate_landed_cost`):** на приёмке разносится `freight_byn`
> (движок `allocate_landed_cost`) и добавляется **пошлина ТН ВЭД** per-SKU (% из фасада
> `core.services.sku_master.landed_inputs` на дату приёмки, к таможенной стоимости goods+фрахт
> после разнесения) — тем же путём, что плановая оценка `_recompute_estimated_landed`, поэтому
> после приёмки себестоимость не «падает» на пошлину. **Горизонт 2:** два FX-курса, брокер/
> страховка/прочие расходы, буфер +10%, частичная приёмка и пересчёт задним числом.

## Куда уходит результат (интеграции)

- **→ WMS:** оприходование остатка по рассчитанной себестоимости (stock valuation).
- **→ 1С (через `integrations`):** вместо ручного ввода закупщиком — приход с
  себестоимостью передаётся автоматически (ERP — источник себестоимости импорта).
- **→ Ценообразование / sales:** landed cost = база для расчёта цены продажи (наценка).

## Данные (предполагаемые таблицы схемы `procurement`)

Новые сущности (расширяют текущую `purchase_request`):
- `purchase_invoice` — инвойс по заявке: поставщик, валюта, сумма, курс, дата.
- `purchase_invoice_line` — строки инвойса: SKU, qty, unit_price.
- `landed_cost_expense` — доп.расход партии: тип, сумма, валюта, `is_recoverable`,
  база распределения.
- `landed_cost_allocation` — результат распределения на SKU: `landed_unit_cost`.

## События (предполагаемые)

- Новое: `procurement.landed_cost.calculated` — payload: себестоимость по SKU.
  Потребители: `wms` (оприходование по себестоимости), `integrations` (передача в 1С),
  ценообразование.
- Согласовать с существующим `procurement.received` (qc): при приёмке сначала
  считается landed cost, затем эмитится приход с уже известной себестоимостью.

## Правила и граничные случаи

- **Возмещаемый НДС** не включается в себестоимость.
- **Многовалютность:** пересчёт по курсу на дату оприходования / ГТД.
- **Частичная приёмка:** расходы распределяются пропорционально фактически принятому кол-ву.
- **Расходы приходят позже товара** (инвойс на фрахт пришёл после прихода) →
  **актуализация (пересчёт) себестоимости** партии задним числом + корректировка в учёте.
- **База распределения по умолчанию** — по стоимости; для тяжёлого/объёмного груза —
  по весу/объёму.
